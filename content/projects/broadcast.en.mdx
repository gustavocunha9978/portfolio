## Problem

Small businesses need to send the same message to contact lists and schedule sends, without mixing one
customer's data with another's.

## Solution

- **Multi-tenant**, with per-user isolation enforced in Firestore _security rules_
- Connections, contacts and messages management with real-time updates
- Send scheduling through a frontend hook, with an optional **Cloud Function** to run the scheduler server-side
- Material UI + Tailwind interface, automated deploy to Firebase Hosting

## Lessons learned

- On Firebase, security rules are the backend: tenant isolation starts there.
